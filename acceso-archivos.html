Cómo descargar un material

Entra a Recursos y materiales y busca el documento por título o etiqueta.
Pulsa Ver para abrirlo en una pestaña nueva del navegador.
Si no se muestra, pulsa Descargar para guardar el PDF en tu equipo.
Abre el archivo con tu visor de PDF preferido.

Por qué a veces falla la vista previa

El sitio se publica con GitHub Pages, que tiene limitaciones al servir archivos binarios desde subcarpetas:

  • Los PDFs en subdirectorios no siempre se sirven de forma directa.
  • La visualización embebida en iframe puede quedar bloqueada.
  • Nombres de archivo con espacios o caracteres especiales pueden producir errores 404.

Por eso la descarga directa es el camino más confiable: funciona en todos los dispositivos, no depende de permisos y te deja el archivo disponible sin conexión.

Alternativas si necesitas vista previa

  • Google Drive: subir el archivo y compartir el enlace de visualización.
  • OneDrive o Dropbox: enlaces públicos con previsualización integrada.
  • GitHub Releases: publicar los materiales como adjuntos de un release.
¿Sigue sin funcionar? Escribe al equipo docente indicando el nombre exacto del archivo y el navegador que estás usando — datos de contacto.
